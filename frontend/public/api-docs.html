API

The data behind the map, as a public HTTP API.

  • Base address: /api/v1. No keys or accounts; every endpoint is a plain HTTP GET but one POST, answered in JSON (the live stream as server-sent events carrying JSON).
  • Times are RFC 3339 in UTC. A time window is half-open, [start, end), given as start and end, or as a rolling duration ending now.
  • Errors are problem details (application/problem+json) with a status and a short reason. 429 means slow down; 503 means the server is busy, so ask again shortly.
  • Requests are rate limited per client (an IPv4 address or an IPv6 /64), by default to 20 a second with bursts of 60.
  • Where a site has a main address, requests to its other addresses (an old domain) are redirected there with 308 Permanent Redirect, method kept: follow redirects, or use the main address.
  • The data is what Meshtastic radios broadcast publicly and what reached the MQTT brokers this site listens to. Message contents are never decoded for display or served (see the privacy policy).
  • Machine-readable description: OpenAPI 3.1, JSON or YAML. This page is built from it, so it always matches the running server.
